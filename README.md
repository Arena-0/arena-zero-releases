# Arena Zero

## Install (Windows)

1. Download **[ArenaZeroLauncher.zip](https://github.com/Arena-0/arena-zero-releases/releases/download/launcher/ArenaZeroLauncher.zip)**.
2. Unzip it into a folder you can write to, for example `Documents\Arena Zero`.
3. Run `ArenaZeroLauncher.exe`, register an account (or log in), and it downloads the game.
4. Press **PLAY**. The launcher keeps the game up to date from now on.

Windows may warn about an unknown publisher the first time: **More info → Run anyway**.

If you played before on this PC, register on the same PC: your fighters and coins carry over to the new account.

## Releases

Every game update is a release here; the launcher reads the latest one automatically.
